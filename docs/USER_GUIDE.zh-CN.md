# Drama Series Agent — 用户使用手册

[English](USER_GUIDE.md) · **中文**

面向 Web 工作台与聊天驱动短剧流水线的使用说明。  
安装与开发环境见根目录 [README 中文版](../README.zh-CN.md)。

---

## 1. 你能完成什么

一个**对话**绑定一部**系列**。在聊天里推进：

1. **立项** — 大纲、世界观、角色、画风、分集目录  
2. **写集** — 单集剧本  
3. **定妆** — 角色形象（可选音色参考）  
4. **出片** — MiniMax H3 Ref2VA 分镜 → 整集 `master.mp4`

启动后的界面入口：**http://localhost:5173/**  
后端 API（必须在跑）：**http://127.0.0.1:8000**

---

## 2. 使用前准备

| 条件 | 作用 |
|------|------|
| 已启动 API + 工作台（`.\start.ps1 -WithWeb` / `./start.sh --with-web`） | 前端依赖 API |
| 系统配置里填好大模型 | 聊天 / 立项 / 写集 |
| **自行安装** [ComfyUI](https://github.com/comfyanonymous/ComfyUI)，并按 [`workflows/selfhost/`](../workflows/selfhost/) **下载齐全模型与自定义节点** | 真正渲染视频（本仓库不附带 ComfyUI/权重） |
| 出片前准备好 `data/cast/{系列}/` 定妆图 | Ref2VA 的 Picture 参考 |

模型文件名与安装步骤见根目录 [README 中文版 · ComfyUI](../README.zh-CN.md#comfyui出片必装--需自行安装)。

浏览器打开 **http://localhost:5173/**。若页面能开但聊天报错，多半是 **8000** 端口 API 未启动。

## 3. 界面一览

| 区域 | 说明 |
|------|------|
| 左侧 — 会话列表 | 一会话一部剧；**新建对话**即新建系列 |
| 中间 — 聊天 | 用中文对 Agent 下指令；工具可在后台跑 |
| 右侧 — **工作台** | 阶段门禁、设定/文学/角色入口、出片进度 |
| 顶部/弹窗 — **系统配置** | 大模型、ComfyUI 地址、**视频工作流**、画幅 |
| 哈希子页 | `#/c/{id}/bible`、`literary`、`cast`、`jobs` |

## 4. 首次配置（系统配置）

1. 打开 **系统配置**。  
2. 填写 **API Key / Base URL / Model**（OpenAI 兼容，如 ModelScope）；可用测试 / 加载模型。  
3. 设置 **ComfyUI 地址**（默认 `http://127.0.0.1:8188`）并测试连通。  
4. 选择 **视频工作流** 与 **宽高比**（默认 `9:16`）：

| 工作流 | 适用 |
|--------|------|
| `…_fast.json` | 默认均衡档（更利于人声） |
| `…_lora.json` | Lightning LoRA 4-step（更快，画质/人声有取舍） |
| `…_turbo.json` | 极速档 |
| `…_r2v.json` | 质量档 / fl2va |

5. 点 **保存**。若已打开系列，工作流/画幅会同步写入该系列运行时。

## 5. 推荐完整流程

### A. 创建系列

1. **新建对话** → 填标题（可加梗概）。  
2. 一会话只做一部剧，不要混片。

### B. 立项（系列圣经）

在聊天中可以说：

- 「根据这个点子做立项，写大纲、世界观、主要角色、画风和分集目录」  
- 「确定大纲、世界观、主要角色、画风并形成文件」

Agent 应调用**立项**工具（后台任务）。完成后：

- 打开工作台 → **系列设定**  
- 核对：`creative-plan`、`world`、`characters`、`art-style`、`episode-directory`  
- 可在设定页手改（保格式），或回聊天让 Agent 改  

**在圣经（含分集目录）齐备前，不要写第一集。**

### C. 写集

示例：

- 「写第1集」/「生成第1集剧本」  
- 「重新生成第3集剧情」→ **只改剧本**（不会自动出片）

到工作台 → **文学** 页查看、修改并**验收**。

### D. 角色定妆

- 聊天里让 Agent 生成角色图，**或**打开 **角色** 页上传。  
- 在角色页验收主演（门禁：角色已验收）。  
- 可选：将 2–15 秒音色放到 `data/cast/{系列}/voices/{角色}.wav`，有利于对白绑定。

### E. 出片

文学 + 角色门禁通过后，明确说：

- 「出片第1集」/「生成第1集视频」/「渲染 EP001」

会构建 `episode-run.jsonl` 并入队 ComfyUI。这和「写第1集」**不是一回事**。

- 进度：工作台 → **生成进度**  
- 产物：`templates/{系列}/output/{EPxxx}/`（分镜 + `master.mp4`）

在系统配置改工作流后，对新渲染生效；已有镜头需 force 重渲。

## 6. 常用话术

| 意图 | 示例 |
|------|------|
| 立项 | 立项；写大纲/世界观/角色/画风/分集目录 |
| 写集 | 写第N集；重新生成第N集剧情 |
| 同句写集+出片 | 写第N集并出片/渲染（须同句说清） |
| 只出片 | 出片第N集；生成第N集视频 |
| 改设定 | 改大纲…；改分集目录… |
| 角色 | 生成角色图；上传定妆 |

## 7. 工作台门禁（S1 → S2）

| 门禁 | 含义 |
|------|------|
| 文学已验收 | 在文学页完成验收 |
| 角色已验收 | 在角色页完成主演验收 |
| 音频 | missing / 已延后 / 已就绪（音色可选） |
| S2 就绪 | 可构建 jsonl 并入队 Comfy |

未就绪时先完成验收，不要跳步硬出片。

## 8. 各页面说明

### 系列设定（Bible）

- 文件在 `dramas/{系列}/`  
- 可手改保格式，或「填入聊天」交给 Agent  
- 改设定影响**下次**写集，不会自动删旧成片

### 文学（Literary）

- 按集的 Markdown 剧本  
- 可上传**本集首帧**（SHOT-001 的 Picture 1）  
- 出片前先验收

### 角色（Cast）

- 预览 / 上传 / 生成  
- 验收主演以通过 S1 门禁

### 生成进度（Jobs）

- **按剧集分块**：每集独立显示完成度（已完成镜数 / 总镜数）  
- **断点续跑**：每集单独「中断」与「断点续跑」（从记录断点或第一枚未完成镜头）  
- **下载成片**：全部镜头完成后显示「下载成片」（`master.mp4`），也可「重拼成片」  
- **分镜预览与重渲**：完成后展开全部分镜可预览；对不满意的镜头填写原因并「重渲此镜」，完成后自动重新拼接成片  
- 入队后在此查看，避免重复发同一句聊天

## 9. 文件落在哪里

| 路径 | 内容 |
|------|------|
| `dramas/{系列}/` | 圣经与文学源稿 |
| `data/cast/{系列}/` | 定妆图与 `voices/` |
| `templates/{系列}/run/` | `*.episode-run.jsonl`、`*.episode-meta.json` |
| `templates/{系列}/output/` | 分镜视频、尾帧、`master.mp4` |
| `projects/{系列}/` | 运行时、聊天记忆、任务 |

## 10. 常见问题

| 现象 | 处理 |
|------|------|
| http://localhost:5173/ 打不开或 API 报错 | 先启动 `:8000` API；检查 `VITE_HERMES_API_BASE` |
| Agent 说「正在生成」但没有结果 | 应走工具调用；刷新消息/工作台 |
| 重生剧情却触发了 Comfy | 只用「重新生成第N集剧情」；出片另说「出片」 |
| 人声不清晰 | 补 `voices/*.wav`；优先用 `fast` 工作流而非 4-step LoRA |
| 第1镜成功、后续失败 | 检查 ffmpeg：`python scripts/doctor.py`（venv 内 `imageio-ffmpeg` 即可） |
| 临时工作流 JSON 不对 | 保存系统配置（含当前系列）；对该镜头 force 重渲 |
| Comfy 报错 | 核对 ComfyUI 地址、H3 模型与所选工作流文件 |
