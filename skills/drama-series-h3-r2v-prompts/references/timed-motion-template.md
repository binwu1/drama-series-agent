# 前中后三段运动模版（R2V 上游正文）

本项目写运动说明时**只用本模版**，不使用 `$short-drama-video-prompts` 七字段。

EP003 等 `剧集/*/storyboard/video-prompts.md` **由本模版 / `drama-series-h3-r2v-prompts` 上游层生成**（不含 `<Picture>` / `<Audio>`）；再由 `build_worker` / `_build_ep00N_run.py` 接成 Ref2VA jsonl。

**语言约定（推荐）**：前/中/后三段内动作为中文**连贯叙述**；台词嵌在叙述里，写成 `角色名：「…」`（中文）。接线重建默认生成 **英文六段 Ref2VA**，对白写成 `says, <d>[Chinese] …</d>`（动作在 `</d>` 外）。

禁止在上游正文写入 `<Picture N>` / `<Audio N>` / `<Subject N>` / `<d>`（由 skill / `_build_ep00N_run.py` 另做）。

## 优先级（比分段算术更重要）

1. **剧情保真（Story Fidelity）**：润色不得改胜负、对白含义、地点、身份、关键事件。
2. **剧情更精彩**：每镜一个清晰戏剧峰值（惊吓、反转、名场面、悬念），少写流水账。
3. **时长内可完成 + 动作预算**：`duration_seconds` 自定，**硬上限 ≤15s**（H3）；每镜 1 主 + 1 转 + 1 结。
4. **出片更稳 + 因果不断**：主动作有方向与反应；身份靠 ref；**镜内 / 镜间各一条因果链**；对白短；后段/结束帧可读、利于下一镜 chain。

**禁止**再写 `0-3秒:` / `3-7秒:` 等秒区间标签。统一用 **`前段:` / `中段:` / `后段:`** 三档节奏（约占开场建立 → 峰值/对白 → 落点/接镜）。

## 借鉴官方 H3 Prompt Writing：让故事「看得见」（必读）

官方 `h3-prompt-writing`（[MiniMax-H3](https://github.com/MiniMax-AI/MiniMax-H3/tree/main/skills/h3-prompt-writing)）强调：描述要**详细、可生成**，不要缩成剧情摘要或参考关系清单。

**分层**：上游本模版仍写中文前/中/后（无六段壳、无 `<d>`）；**接线层**默认输出官方 Ref2VA **英文六段**（`subject_definitions` / `summary` / `retention_analysis` / `detailed_description` / `overall_soundscape` / `non_diegetic_music`），详见 [ref2va-en-official.md](ref2va-en-official.md)。遗留秒区间中文可用 `_build_run.py --format timed`。

### 借鉴什么（写进前中后正文）

每一镜、尤其是**前段**，尽量覆盖官方所说的可见维度（揉进同一段叙述，不要拆字段）：

| 维度 | 问自己 | 写法提示 |
|------|--------|----------|
| **构图 / 站位** | 谁在画面哪一侧？远近？ | 「左侧布尔玛抱盒贴云心，右侧悟空棒尖斜指闸门」 |
| **环境 / 空间** | 在什么场？有什么可读地标？ | 屋顶高台、锈桁架、窄钢廊、浪尖、塔台屏 |
| **光与色温** | 主光从哪来？什么颜色在咬画面？ | 红锁定光、冷顶光、舷窗病态红、浪尖逆光 |
| **动作 → 状态变化** | 开始怎样、结束怎样？ | 「盒滑出→按死盖」「丝缠云→棒斩断」 |
| **微反应** | 脸、手、呼吸、视线有无一口戏？ | 死扣搭扣、眼神对齐、先愣再笑、膝几乎跪仍顶住 |
| **同步声响** | 此刻听得到什么物理声？ | 嵌进动作句：熔栏喷火星、锁定尖啸钉死（描述性，勿「『砰』的一声」） |
| **信息亮点** | 屏字、倒计时、雷达、埋点道具？ | 屏角倒计时亮起、腰带胶囊晃光——须**先看见再被说** |

**黄金句式（方案 A · 每镜整条链尽量命中）**：  
`空间站位 + 主体动作 + 动作目标/方向 + 对方反应 + 状态变化/结果 + 微反应 + 短对白 + 嵌入动作的物理声`

> **前段 → 中段 → 后段** 是一条动作因果链，不是三个独立画面。

### 前 / 中 / 后 怎么「变丰富」而不变乱

| 段 | 职责 | 丰富度着落点 |
|----|------|----------------|
| **前段** | 建立画面 | 构图、环境、光、威胁登场；**少对白**；写清左右/远近站位 |
| **中段** | 峰值 + 口吻 | **主动作 → 反应 → 结果**；由动作触发的微反应；**短对白**；声响跟峰值同步 |
| **后段** | 落点 / 接镜 | 可读结束态、空间仍同一条因果；可留一句威胁回响 |

同一镜只保留**一条**因果主链；丰富 = **同一事件的感官层次**，不是并行两场戏。

## 方案 A 硬规则（运动润色）

### Story Fidelity · 剧情保真

允许：补动作细节、空间、微反应、物理声、简洁运镜；把摘要写成连续动作。  
禁止：新增角色/武器/能力；改胜负或攻击结果；改对白含义；改场景地点或身份；新增关键剧情事件。  
上游只有 plot summary 时：选**低风险、可执行、不改结果**的细节。

### Action Causality · 动作因果链

必须：`动作发起 → 对象反应 → 状态变化 → 下一动作/结束态`。  
禁止连续罗列互不因果的动作。

**Bad：** `布尔玛冲刺、挥拳、跳跃、旋转。孙悟空闪避、出拳、释放能量。`  
**Good：** `布尔玛从左侧冲向孙悟空挥拳，孙悟空向右侧躲开拳锋；布尔玛因惯性前倾半步，借旋身重新站稳，孙悟空抓住这一瞬间逼近。`

### Action Budget · 动作预算

每镜：**1 个主要动作 + 1 个动作转折 + 1 个结束动作**。  
禁止单镜连续 >3 个独立高强度动作；复杂打戏**拆镜**。  
与下表「合理密度」一致：过密则加长（≤15s）或拆镜。

**Good（一镜）：** `冲刺 → 挥拳 → 被闪避 → 停住`  
**Bad：** `冲刺 → 三拳 → 回旋踢 → 跳跃 → 能量弹 → 爆炸 → 翻滚 → 起身`

### Spatial Continuity · 空间连续

每镜至少明确 **两个** 空间关系：左/右、前/后、远/近、面向、移动方向、相对位置。  
默认继承上一镜结束站位；除非剧情明示，禁止无因果换位或瞬移。

### Micro-reaction · 微反应

中段 ≥1 个**由前一动作触发**的可视微反应，例如：眼神跟随、视线转移、肩膀受力、重心切换、呼吸变化、衣摆/头发被气流带动、短暂失衡、蓄力紧绷、攻击落空后的惯性。  
禁止独立贴「露出惊讶表情」类无触发微反应。

### Dialogue Budget · 对白预算

对白服务动作，不抢主动作时间。  
- **每镜硬性 ≥1 句**（禁止无对白镜；拆镜不得制造静默桥镜）  
- 单镜默认 **1–2 句**；单句尽量 **≤12 个汉字**；高速动作镜可用 **≤6 字** 短喊  
- 长对白只放低运动强度镜；邻镜分摊台词，但**每镜仍至少留一句**  
- 上游：`角色名：「…」`（名与冒号紧挨）；**不要**写 `<d>`  
- **朝向绑定**：说话人面向对方/目标物 + 对方可见反应；禁止「只张嘴、不看人」。接线层英文细则见 [dialogue-facing-bind.md](dialogue-facing-bind.md)。  
- **对白后静默（H3 native · 必守）**：`<d>` 只标定台词，**不保证**其后静音。接线层（起死 `_build_run`）在每个 `</d>` 后注入**纯画面**锁：`说完后嘴唇保持闭合，只保持姿态。` 上游不必手写这句。  
  **严禁**写入会被念出的元指令：`不说话` / `不再说话` / `不念旁白` / `禁止发声` / `保持沉默` / `人物声音行为约束` 整段等（H3 native 常把这些字读出来）。静默只写**看得见的**嘴唇/姿态。短喊镜压到约 **7s**；**对白尽量靠镜末**，`</d>` 后只留极短闭口姿态；少把大段中文叙述放在喊话之后（易被续念）。

### Diegetic Physical Sound · 物理声

≥1 个物理声**绑定动作**，写进叙述句。  
**Good：** `拳锋擦过空气，衣摆被高速气流扯出呼啸。` / `攻击相撞，冲击力震落墙面碎石。` / `眼眶里一粒干土轻轻掉落，带起极轻的砂粒细响。`  
**Bad：** `音效：拳击声、风声。` / `soundscape: cinematic ambience.` / `细响几乎听不见。`（可听度元评论，易被念出）

**禁止可听度元评论**：`几乎听不见` / `听不见` / `听不到` / `微不可闻` / `几乎无声`.要轻就写物理事件或「极轻的…细响」，不要写「听不听得见」。

**禁止文学旁白式表情**：把「笑」当抽象名词写进叙述（如 `庄子的笑僵了一寸；司命的笑已经很稳`）易被念出。改成可见器官：`庄子嘴角笑意一滞；司命嘴角仍稳稳扬着`。

**禁止叙述里的「对…说」**：`杨大对巡士说，不看庄子` 易被念成旁白。改成可见朝向：`杨大面向巡士，目光不看庄子`。对白只用 `角色：「…」`（接线成 `<d>`）。
### Camera · 运镜

只写一句 `运镜:`，须尽量含：跟随谁、移动方向、动作高潮时如何变。  
优先：跟拍、推近、横移、环绕、拉远、轻微手持震动。  
避免：焦距/光圈/shutter/ISO、9:16、电影感空话。一镜最多 **1–2** 种运镜变化。

**Bad：** `运镜：动态运镜，电影感，快速切换。`  
**Good：** `运镜：贴着布尔玛冲刺方向横向跟拍，拳锋擦过时短促推近，两人拉开后再缓缓拉远。`

### H3 Motion Feasibility · 可执行性

润色后自检：主动作/主体/目标/方向/结果是否清楚；角色尽量 ≤3；同时复杂动作 ≤2；无瞬移、无精确手指微操、无瞬间变身换装换位、无镜内硬切多机位。  
任一项失败 → **优先简化动作**，不要继续加形容词。

### 结束帧 vs 后段

| 字段 | 用途 | 是否进 H3 |
|------|------|-----------|
| **后段** | 镜内动作落点 / 结束态 | ✅ 进 `video_prompt` |
| **结束帧** | 给人、拆镜、镜间 chain 的可读定格 | ❌ `_build_run` **剥离** |

二者可略重叠（同场同态），**禁止**在结束帧另起一场戏。接线层可能再追加强化结束约束——那是接线产物，不是上游文学扩写。

### 明确不借鉴（格式禁区）

- 不写 `summary` / `retention_analysis` / `overall_soundscape` / `non_diegetic_music`
- 不对白用 `` `<d>[Chinese] "…"</d>` ``
- 不写 STYLE 元指令、配乐段落、「开场仅环境底噪」类脚注
- 不把正文改成英文长文（官方默认英文；本流水线上游默认中文）
- 有资产图的角色：**不写外貌百科**（发型服装以 Cast 静帧为准）；只写动作、表情、站位、持物
- 运镜仍只一句 `运镜:`，不堆 35mm / 浅景深 / 9:16

### 贫乏 vs 丰富（同剧情）

**贫乏（剧情摘要）**：他们躲开红光，布尔玛很害怕。

**丰富（可生成）**：红光柱加粗直取云心；悟空猛扳云沿硬侧翻，布尔玛整个人压在盒上，云缘擦过红光外皮爆出一串火花雨——她指节发白死扣搭扣。布尔玛：「差一点点——！」

## 润色验收（起死 / 竖屏）

画面感润色写在上游 `video-prompts.md`，**接线层不扩写**。竖屏毒日胶片词只嵌进段叙述，**禁止**单独 STYLE 段。

可用环境光写法（例）：正午硬侧光、晒褪土赭、漂白浅空、贴地热影、薄汗与盐霜、冠带被热风掀角。

### 起死对照 · 口渴

**贫乏：** 他拨开浮萍捧水喝，喉结滚动。喘定，抬眼看空路。庄周：「出门没水，真不如化蝴蝶。这儿也没有花。」

**丰富：** 竖屏中近，庄周偏土路左侧，身后马只露半臀与颈；正午硬侧光刮过道冠与干裂嘴唇，浊水洼反一点白。他蹲低拨开浮萍，捧起浊水，喉结一滚，水从指缝滴回洼里溅起细响。喘定，目光抬向空路——没有树。庄周：「出门没水，真不如化蝴蝶。这儿也没有花。」

### 起死对照 · 敲骨

**贫乏：** 他用鞭杆轻敲两下。庄周：「您是倒行逆施成这样的？」

**丰富：** 中景，蓬草里白骨从土里露半个眼眶；他用鞭杆笃两下，骨面发出干短的磕响。侧光贴着道冠与颧骨。庄周：「您是倒行逆施成这样的？还是没饭吃成这样的？」第三下敲落，他自己先笑出一口气。

### 润色自检（缺一项就改 · 方案 A）

- [ ] Story Fidelity：未改胜负/对白义/地点/身份
- [ ] 前段：站位 + 环境 + 主光，至少两项；空间关系 ≥2
- [ ] 中段：主动作 → 反应 → 结果；≥1 由动作触发的微反应
- [ ] 动作预算：≤1 主 + 1 转 + 1 结；未堆 >3 高强度独立动作
- [ ] 后段：可读结束态，能接下一镜
- [ ] **每镜 ≥1 句对白**（默认 1–2；≤12 字；动作镜可短喊）；全镜 ≥1 物理声嵌在动作句
- [ ] 运镜一句含跟随/方向/高潮变化
- [ ] Feasibility 通过；无外貌百科、无 STYLE、无秒标、无上游 `<d>` / Picture / Audio
- [ ] 有 `结束帧:` 时与后段同场同态（接线会剥掉结束帧）

## 因果关系（镜内 + 镜间 · 必查）

### 镜内（前→中→后）

- 顺序固定：**动作发起 → 对象反应 → 状态变化 →（若开口）边做边说 → 落点/结束态**。
- 后一段必须能回答「为什么会发生」：因前一段的动作、威胁或信息，而不是另起一场戏。
- 同一镜只保留**一条**因果主链；旁支最多一句环境反应，勿并行两场独立高潮。
- 遵守 **Action Budget**：1 主动作 + 1 转折 + 1 结束动作。

### 镜间（SHOT → SHOT）

写完一集后，按镜号扫一遍「结束帧 → 下一镜开场」：

| 检查项 | 要求 |
|---|---|
| 空间/状态 | 下一镜开场能接上一镜结束帧（同场 chain），或**明示**换场/反切 |
| 道具/装置 | 关键道具须先**埋点**再亮相（腰带晃一下 → 下镜抽出）；禁止无来源突然掏出 |
| 信息/倒计时 | 角色口中的设定须先在画面或台词里**亮过**（屏角倒计时亮起 → 后镜再说「还在跑」） |
| 动机 | 本镜峰值是上一威胁/决定的结果（逃过一阶段 → 敌方开二阶段；定计 → 赴核心舱） |
| 反切 | 若回到更早同场（如塔台插镜后再回云面），正文写清「回到…」，接线用 `independent` + 指定更早镜尾帧，**勿**误接插镜尾帧 |

**反例（软缺口）**：关键道具首镜才凭空出现；角色先喊「倒计时」却从未亮过倒计时 UI/信息。

**正例简述**：003 腰带胶囊晃光 → 005「抽出刚才晃过的胶囊」；004 屏角倒计时亮起 → 011/012 呼应未清零。

### 自检口诀

上一镜结束帧里**看得见的东西**，下一镜要么还在、要么交代去向；下一镜**新掏出的关键物/新信息**，前面至少埋过一笔。

## 合理密度（经验 · 对齐 Action Budget）

| 镜长（建议） | 适合装的戏 |
|---|---|
| 4–6s | 一个动作峰值 + 一句短对白 |
| 7–10s | 一个主动作 + 一个必要反应/对白 |
| 11–15s | 一场小高潮（仍 **1 主 + 1 转 + 1 结**；不要塞两场独立大战） |

过密就**加长本镜**（仍 ≤15）或**拆镜**；不要靠「三段写满」假装装得下。丰富度优先加在**微反应与光/声**，而不是再加一条支线。

## 强制字段

- 分段节奏：**`前段:` / `中段:` / `后段:`**（三档；勿用秒区间）
- **段正文 = 连贯叙述**（见下节）：视觉动作、拟声、对白写进同一段句子，**不要**再单开 `视觉:` / `对白:` 行
- **`运镜:`** 一句短中文：跟随谁 + 方向 +（可选）高潮变化；不堆 35mm / 浅景深 / 9:16
- **`结束帧:`** 可读、可接下一镜；与后段同场同态；**接线层剥离，不进 H3**

**不再要求**单独的 `相机参数:` / `摄影机 camera:` 长句。焦距、景深、画幅、光比等技术堆砌默认省略（画幅由工作流决定）；**光与色**请写进段叙述，不要堆在运镜行。

兼容：旧稿若仍写 `摄影机 camera:` / `相机参数:`，重建脚本会收成一句简短 `运镜：…`，并丢弃参数堆砌。

## 前中后写法（重要 · 利于视频生成）

每个 `前段:` / `中段:` / `后段:` 写成**一条（或少数几句）连贯叙述**，把「看得见的事」和「说得出的话」揉在一起，像分镜旁白，而不是字段清单。

**要：**

- **镜内因果**：发起 → 反应 → 状态变化 → 落点（方案 A）
- **画面丰富**：站位 + 环境光 + 状态变化 + 由动作触发的微反应
- **空间连续**：左右/远近/面向；默认继承上镜结束站位
- **镜间因果**：结束帧可接下一镜开场；关键道具/倒计时等须先埋后用
- 声响写成**环境/物理描述**嵌进动作（如「金属栏瞬间熔穿喷火星」「锁定尖啸骤然钉死」）
- **避免**「『砰』的一声 / 『嘀』的一声 / 音调一点点」这类易被模型当台词念出的拟声短语
- 对白短（预算内）、有口吻；嵌在动作句中，且 **角色名与冒号紧挨**：`……。布尔玛：「短句」悟空：「短句」`（不要写成 `布尔玛急喊：「…」`，接线器认不出说话人）
- 上游 **禁止** 写入 `<d>` / STYLE / `overall_soundscape`；`<d>` 仅由接线重建生成

**不要：**

- 同一段拆成 `视觉:` 一行 + `对白:` 一行
- 独立 `音效:` / `SFX:` 行
- 剧情摘要句（「他们成功逃脱」「气氛紧张」）代替可见动作
- 超长独白、招式枚举、与因果无关的服装百科（有 Cast 时）
- `0-3秒:` 等秒区间标签；冗长 `相机参数:` 清单
- 润色时改胜负/增能力/改对白含义（违反 Story Fidelity）

## 声音写法

- 离散物理声写进段叙述，用描述性措辞，少用「『X』的一声」模板。
- 接线后角色只念 `<d>[Chinese] …</d>` 内台词；动作写在 `</d>` 外；**禁止**追加「不说话 / 禁止发声 / 只念某某标签」类约束句（会被念出来）。
- **不要**单独写配乐段；需要情绪时用画面光色与动作节奏暗示即可。

## 禁止无对白镜（H3 native · 硬规则）

《起死》/短剧接线：**每一镜必须有至少一句** `角色名：「…」`（接线成 `<d>[Chinese]…</d>`）。  
禁止纯动作静默镜；禁止「准备开口一镜 / 台词下一镜」把台词抽空——拆镜时**每半镜仍至少留一句短对白或短喊**。

仍禁止写入会被念出的元指令：`不说话` / `不张嘴` / `没有任何说话` / `保持沉默` / `禁止发声` / 长段 `人物声音行为约束`。  
对白说完后只写看得见的嘴唇闭合 / 姿态（接线层也会注入视觉闭口锁）。

### （已废止）无对白模版 — 勿再使用

高速动作镜也要嵌短喊，例如：

```text
前段:杨大揪住袍袖，正午硬光打在袖口。两人三四分侧对，不看镜头。
中段:袍料发脆嘶的一声。庄周面向杨大，目光盯住那只揪袖的手。庄周：「别扯！」杨大肩一沉，裂口拉长一线。
后段:袖口裂开一线。两人嘴唇闭合，对峙未散。
运镜: 袖口裂帛特写再拉开对峙
结束帧:袖口裂开一线，杨大仍揪着。
```

## 模版

```text
前段:夜雨天台，铁丝网在闪电里发白；她站在护栏内侧，雨水打湿头发和风衣下摆。她缓缓转身，腰间抽出两把蝴蝶刀，刀面映着远处闷雷的光。
中段:目标A冲来挥拳，她侧踢划开手臂一脚踹在胸口将其逼到天台边缘；目标B持匕首刺来，她侧身躲开抓住手臂撞向护栏甩出去，重物撞上金属栏震出短促回响。她指节发白，呼吸却稳。
后段:目标C持武士刀劈来，她用蝴蝶刀格挡，火花四溅，刀刃相击脆响，她低声说：「下一个。」
运镜: 低机位跟拍后短促前推
结束帧:她持双刀对峙，目标C被格在护栏外。
```

（上例约 10–13s：一场连贯近身；前段建空间与光，中段峰值+微反应，后段对白落点；运镜只一句。）

## 出片更稳：少写这些

- 同一段里多人各干一件互不因果的事
- 镜间跳空间却不写「回到 / 切入 / 反切」；关键道具无埋点突然亮相；口中设定画面从未出现
- 超长对白、枚举式招式清单
- 与剧情无关的服装百科、反复「围巾被风吹」
- 未声明的镜内硬切、跳空间
- 独立「音效:」/「视觉:」/「对白:」清单式分行（改写成连贯叙述）
- 秒区间标签；`35mm / 浅景深 / 9:16 / 高对比` 类技术堆砌
- 抽象情绪词堆砌（「史诗」「绝望」「燃」）而无可见动作

## 自检

- [ ] ≤15s；戏在该秒数内演得完（宁可镜更长或拆镜）；动作预算未超
- [ ] Story Fidelity；有戏剧峰值；结束帧可读且能接下一镜（或明示反切/换场）
- [ ] **画面丰富**：前段有站位/环境/光；中段有因果链+微反应；不是剧情摘要
- [ ] **空间连续**：≥2 空间关系；默认继承上镜站位
- [ ] **镜间因果**：道具已埋点；信息/倒计时已先亮；动机承接上一威胁/决定
- [ ] 仅 `前段`/`中段`/`后段` + 一句含目的的 `运镜:`（+ 可选 `结束帧:`，接线剥离）
- [ ] 段为连贯叙述：视觉+拟声+对白同段，无独立 `视觉:`/`对白:`/`音效:` 行
- [ ] 对白为嵌套的 `角色名：「…」`，**每镜 ≥1 句**（默认 1–2）；接线后每个 `</d>` 带**视觉**闭口锁；短喊镜勿虚高时长
- [ ] Feasibility 通过；无供应商标签；无 soundscape / `<d>` / 配乐段
- [ ] **禁止无对白镜**；对白后无续念风险（视觉闭口锁 + 后段非口头化）；无 speech-meta 诱导发音
